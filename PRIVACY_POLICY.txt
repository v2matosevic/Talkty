Talkty Privacy Policy
=====================

Last updated: 3 October 2026

Version2 operates Talkty. This document describes the data used by the Windows
application and distinguishes local dictation from optional connected features.

Contact: office@version2.hr
Website: https://version2.hr
Source and releases: https://github.com/v2matosevic/Talkty


1. LOCAL DICTATION
------------------

Local speech recognition runs on your PC. Microphone audio is held in memory
during recording and processed by the selected local model. Local dictation does
not send audio or transcript text to a model provider. Model downloads and update
checks use the internet; the core local recognition path works offline.

Completed text is kept in local transcription history. Depending on your output
settings, Talkty copies it to the Windows clipboard, pastes it into the selected
application, or keeps it in history only. Those applications and the Windows
clipboard have their own handling of the text after delivery.


2. OPTIONAL CLOUD FEATURES
-------------------------

Selecting a cloud transcription model sends the recording and applicable
language/vocabulary hints to OpenRouter and its model providers. Prompting sends
transcript text for rewriting. Optional prompt planning and fidelity checks can
send transcript/prompt text to a decision model. These features use your configured
OpenRouter key and can cost per request. Provider data handling is governed by
the services you choose, rather than by the local-recognition behavior above.

With transcription during pauses enabled, the selected cloud model can receive
audio before you press Stop. An early request may already have been accepted and
billed when you cancel or continue speaking. Cancelling the local request does
not retract data already received by the provider.

Cloud recordings are saved locally at Stop using Windows current-user encryption
for recovery. They are removed after successful history saving or when you choose
Discard. A failed take can remain recoverable across app restarts. Early in-flight
audio is not a persistent recovery copy.


3. OPTIONAL LOCAL INTEGRATIONS
-----------------------------

Command mode sends the transcript and captured foreground-window information,
including the window title, to a separately configured service on this PC. The
service owns execution and any further network access. It is not bundled with
Talkty. Uncertain execution is not automatically repeated.

Direct ADE dictation shares the complete output with the local workspace/agent
draft you explicitly select. The destination is frozen when recording starts.
Talkty stages the instruction without automatically sending an agent turn. ADE
owns accepted draft data; the selected agent/provider can receive it when you send
the draft. Unverified handoffs are saved in Talkty's local CaptureOutbox using
Windows current-user encryption until a verified retry or discard.


4. LOCAL STORAGE AND DIAGNOSTICS
-------------------------------

Settings, history, diagnostic logs, models and recovery files are under
%APPDATA%\Talkty\. Diagnostic logs can contain dictated text and window/application
information. History and logs are ordinary local files, not encrypted recordings.
OpenRouter credentials and uncertain recovery/capture payloads use Windows DPAPI
encryption tied to the current user.

Talkty does not send analytics, advertising or telemetry. Model downloads and
update checks contact the configured download hosts and GitHub; like other HTTP
requests they expose connection information to the receiving host.


5. CONTROL AND REMOVAL
---------------------

You can select local recognition, disable connected features, clear transcription
history, and discard recoverable recordings or capture handoffs. Clearing history
does not erase diagnostic logs or data already shared with another application or
provider. The uninstaller asks whether to remove user data and defaults to keeping
it. You can remove remaining Talkty files in your user-profile directory when the
application is closed.

This document does not guarantee security or the behavior of third-party services.
Keep your operating system and security software updated and choose output
destinations and cloud providers according to the data you intend to dictate.


6. CHANGES AND CONTACT
---------------------
